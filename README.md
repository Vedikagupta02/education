# AI-Powered Education & Career Guidance Platform

This is a modern education platform built with Next.js 14 and TypeScript, designed to provide personalized career guidance for students. It uses Google's Gemini AI API to deliver intelligent career recommendations based on student interests, goals, and problem-solving skills.

## Features

### AI-Powered Career Guidance
- Personalized career advice based on:
  - Subjects of interest
  - Career goals
  - Problem-solving skills
- Clean, bullet-point format responses
- Modern UI with smooth animations using Framer Motion
- Responsive design for all devices

### Class Management System
- Learning modules and assignments for Classes 3 to 10
- User-friendly dashboard with organized subjects
- Enhanced navigation with collapsible sections
- Clean and consistent UI design

### Professional Contact Page
- Clean and intuitive contact form
- Social media integration
- Location information display
- Professional communication interface

## Tech Stack

| Layer       | Technology                          |
|-------------|-------------------------------------|
| Frontend    | Next.js 14, React, TypeScript       |
| Styling     | CSS, Framer Motion                  |
| AI Backend  | Google Gemini API                   |
| Backend     | Flask                               |
